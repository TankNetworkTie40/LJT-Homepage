Junteng Liu is the first author of this paper. This work discovers a previously unknown universal truthfulness direction (hyperplane) that exists consistently inside different large language models, allowing control over factuality of generation via simple activation edits without affecting other generation capabilities. Open-source implementation code is publicly available on GitHub.
