Junteng Liu is the first author of this work. This work proposes SynLogic, a large-scale verifiable reasoning synthesis framework that automatically generates high-quality, fully checkable logical reasoning datasets, which significantly improves large language models' in-context and out-of-distribution logical reasoning performance after fine-tuning, with open-source GitHub code available.
